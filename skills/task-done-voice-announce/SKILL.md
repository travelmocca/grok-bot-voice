# 任务完成语音播报

## 何时用
- 一项委托任务刚完成，需要让用户立刻知道结果
- 敲定了会长期生效的配置/偏好，需要口头确认
- 用户明确要求「用声音说一下」

不要用于：纯闲聊追问、还在进行中的中间步骤（除非用户要求全程播报）。

## 话术
1. 开场固定：「嗨，我这里有个信息。」
2. 接着一两句口语摘要：做完了什么、结果怎样、用户要不要做什么。
3. 完整说完的句子，不要列表、不要 markdown、不要念路径堆砌。

## 播报通道（按优先级）
在用户已连接的 Mac 桌面上执行（用其 machineId；用户从某台机器发消息时默认那台）。

1. **优先：edge-tts + afplay**
   - 若存在 `~/.grokbot-tts/announce.sh`，调用：
     `~/.grokbot-tts/announce.sh "完整播报文本"`
   - 脚本默认音色可用环境变量 `GROKBOT_TTS_VOICE` 覆盖；未设置时用工作向、清楚稳妥的中文神经网络音色（常见默认：`zh-CN-YunxiNeural`）。
   - 若无脚本，等价流程：
     `edge-tts --voice "$VOICE" --text "..." --write-media ~/.grokbot-tts/last-announce.mp3 && afplay ~/.grokbot-tts/last-announce.mp3`
2. **后备：系统 say**
   - `say -v Tingting -r 180 "..."`（或用户指定的系统音色）
3. **再后备：聊天文字**（必要时可加聊天语音备忘）
   - Mac 离线、本地执行被拒、或 TTS 失败时，用文字把同一摘要发到聊天，并说明外放失败。

## 选音色标准
- 优先适合工作：清楚、稳、少抢戏
- 不为「有特色」而选花活/卡通音色
- 用户已指定默认音色时，严格使用用户指定

## 与「默认执行」的关系
本 skill 只规定**怎么播**。是否在每次任务完成后自动播，由该助手的偏好/人设记忆决定（相当于 hook）。助手应在适用时机主动加载并执行本 skill，而不是等用户每次 `@`。

## 完成后
聊天里仍应用简短文字交付结果（附件、链接等）；外放是摘要，不替代可见交付物。
